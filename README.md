# Calculadora RPN

## Exemplos de expressões:
Expressão: 3 + 5 * 2 <br>
RPN: 3 5 2 * + <br>
Resultado: 13.0

Expressão: (10 + 2) * 3 <br>
RPN: 10 2 + 3 * <br>
Resultado: 36.0

Expressão: 8 / 2 + 4 <br>
RPN: 8 2 / 4 + <br>
Resultado: 8.0

Expressão: 5.5 * 2 + 1.5 <br>
RPN: 5.5 2 * 1.5 + <br>
Resultado: 12.5

Expressão: (2.5 + 3.5) / 2 <br>
RPN: 2.5 3.5 + 2 / <br>
Resultado: 3.0
